# EMI Shielding Using Polypropylene Composites

## Overview
This repository contains an academic research project completed during the 4th semester
as part of the Material Science and Engineering coursework.

The study focuses on analyzing the electromagnetic interference (EMI) shielding effectiveness
of polypropylene-based composite materials.

## Key Highlights
- Academic research project (coursework-based)
- Literature review on EMI shielding mechanisms
- Comparative analysis of polypropylene composites
- Focus on engineering and electronic applications

## Course Details
- Course: Material Science and Engineering
- Semester: 4th Semester
- Institution: IGDTUW

## Note
This work was conducted for internal academic evaluation and has not been published in any journal or conference.
